# 常见错误对照清单 (2026-08-25 整理)

## CI / 构建
| 错误 | 根因 | 修复 |
|---|---|---|
| Plugin [id: 'rikkahub.android.library'] was not found | upstream convention plugin 我方不存在 | videogen 等模块用 alias(libs.plugins.android.library) |
| project ':X' does not specify compileSdk | 我方不用 convention plugin 自动注入 | 各模块显式 compileSdk = 37 |
| Unresolved reference 'ktx'/'compose' (gradle.kts) | libs.versions.toml 无对应 alias | 用 upstream 实际依赖集合, 不杜撰 |
| Unresolved reference 'Fullscreen'/'SearchMode' (ChatInput.kt) | upstream 新版 ChatInput 依赖我方 base 不存在的类型 | 9f0a5ac4 base 用自有 ChatInput 版本 |
| INSTALL_FAILED_VERSION_DOWNGRADE | versionCode 不一致: 已装 9999 再装 2500 判降级 | 所有对照包 versionCode 全局统一 9999 |
