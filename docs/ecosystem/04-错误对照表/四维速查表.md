## 版本回滚优先级速查

问题域 → 首选回滚版本：

1. 连接/流式中断 → 当前 v3.5.17 已是最优（v2.9.8 重试 + HTTP/1.1 + keepalive 60s + 无静默）
2. 缓存问题 → v3.5.11（SystemPromptBuilder）
3. 工具域分类问题 → v3.2.2（域分类引擎）
4. MCP 问题 → v3.5.13（STDIO 前）或当前修复态
5. 收尾问题 → 当前 v3.5.17（NonCancellable）
6. 传输层整体崩坏 → v3.5.0 的回滚方案（8 文件 → 3.2.2）

## 使用规则

- 新问题先查此表：命中 → 按"当时修改"方向修复，按"回滚参照"做预案
- 未命中 → 走迭代框架完整流程（定位→对比→澄清→规划→修改→验证→推送→记录）
- 每次修复后更新此表（新问题加行，已修问题更新现状）
