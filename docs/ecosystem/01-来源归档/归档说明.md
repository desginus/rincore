## 二改版 RikkaHub agent

- 远程：https://github.com/ExTV/rikkahub-agent
- 本地：/workspace/fork-ref/rikkahub-agent-src（无 git 历史，文件快照）
- 特性：80+ 设备工具、AI 编写工作流、定时任务、内置浏览器、SSH、屏幕自动化、文件管理器、音乐播放器、语音转录、本地 LLM、Telegram 机器人

## 恢复方法

- 原版 2.4.5 代码：cd /workspace/rincore-src && git archive upstream-try/master | tar -x -C /目标目录
- 二改版 agent：tar xzf rikkahub-agent-fork-ExTV.tar.gz -C /目标目录
- RinCore 任意版本：cd /workspace/rincore-src && git checkout <版本提交>（版本链见 03 修改全记录）
