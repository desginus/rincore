## 四、消息页渲染深度优化 (v3.6.69)

针对用户反馈"上下滑动特别卡、不跟手、阶段性卡死 60Hz"，三处渲染优化：

### 1. LazyColumn 加 contentType

ChatList 的 itemsIndexed 此前无 contentType，所有消息条目视为同类型，滚动时无法按类型复用。加 contentType = currentMessage.role，按角色分类型缓存。

### 2. MarkdownBlock 初次解析异步化

根因：MarkdownBlock 首帧 `remember { mutableStateOf(parseMarkdown(content)) }` 在主线程同步解析 Markdown AST。LazyColumn 滑动回收重建条目时反复同步解析长消息，阻塞主线程，是滑动卡顿不跟手的直接原因。

修复：初始 data 为 null（空占位），LaunchedEffect + snapshotFlow + flowOn(Dispatchers.Default) 后台解析后填充。主线程不再被 Markdown 解析阻塞。

### 3. 流式 UI 节流 50ms → 100ms

流式期间重组频率从每秒最多 20 次降到 10 次，进一步降低流式输出期间的掉帧与滑动卡顿。

### 上下文降维改名
