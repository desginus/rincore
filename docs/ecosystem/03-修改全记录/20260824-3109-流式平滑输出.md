# v3.10.9 — 流式输出平滑整形 (2026-08-24)

## 需求
服务端块到达 → 用户看到"一节一节窜": 要求逐字符平滑输出, 速度动态
对齐服务端且变化呈平滑曲线, 零首字延迟。

## 实现 (SmoothStreamingText, UI 渲染层)
- 观察 target 增量估算服务端瞬时速率 → EMA 平滑为 rateTarget
- 输出循环 33ms/拍 (30fps), rateCurrent 一阶低通向 rateTarget 渐变
- 首字零延迟: 新内容首帧立即显示 1 字符
- loading 闸门: 生成中平滑; 完成/历史/编辑/版本切换直接全文
- 速率钳制 8-400 字符/秒

## 影响面检验 (整体)
- 数据流/落盘/缓存: 零接触 (纯显示层)
- 工具调用: 工具轮消息不走正文渲染; USER 消息不平滑
- 渲染: 平滑期旧内核 (异步解析), 完成切新内核 — 30Hz 不卡主线程
- 多版本切换: loading 闸门防重放
