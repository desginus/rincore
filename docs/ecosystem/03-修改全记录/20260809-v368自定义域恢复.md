# 2026-08-09 v3.6.8 — 自定义域恢复 (工具系统报废根因)

## 根因
v3.5.40 用户决策移除自定义域: domainSource 不再加入 customDomains →
自定义域退出域体系 (UI/层1/Invoke Tools/List Domains 全部同步消失)。
但配套工具 (manage_domain create/move) 与 UI 新建域功能未同步移除,
仍在写 customDomains — 写成功 (settingsFlow 更新) 但视图 (domainSource)
不读 → 模型调用工具/UI 手动新建全部"无反应"。

用户实测: move_tool_to_domain 返回清单已是新状态 (工具内部 allValid 含
customDomains), 但系统 Prompt/域管理 UI/List Domains/Invoke Tools 全旧 —
完美对应 domainSource 不含 customDomains。

## 修复 (v3.6.8)
1. domainSource 恢复 customDomains (规范化 DomainInfo: path=fullPath/
   parent/displayName/description/keywords) — 新建域/移动目标域全部可见
2. classifyByName 恢复自定义域关键词匹配 (枚举域匹配后兜底)
3. 技能归根域保持 (v3.5.47 缓存根治)
4. 缓存影响: customDomains 是用户配置 — 创建/修改后 layer1 同步变化,
   缓存随配置失效 (合理: 新配置无旧缓存)
5. 逻辑测试 37 项通过 (新增: 新域进视图/进树/关键词分类/子域)

## 全链路 (恢复后)
UI 新建域 → customDomains → domainSource → 树/计数/帮助/List Domains
manage_domain create → 同上
move_tool_to_domain → 目标域校验 (allValid 含 customDomains) → 写
override → 分类解析 (valid 含自定义域) → 工具归新域
