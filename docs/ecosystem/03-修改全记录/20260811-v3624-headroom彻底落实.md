# 2026-08-11 v3.6.24 — Headroom 上下文降维彻底落实

## 功能定义
对话两种模式, 右上角「上下文降维」开关隔离:
- 关闭 (默认): 零干预, 消息原样发送, 所有功能与之前完全一致
- 开启: 所有会发送向 API 的消息内容都经过确定性规则压缩

## 压缩范围 (开启时)
1. 工具输出 (Tool.output Text): 内容级压缩
   - JSON 数组: 去重 / 常量字段提取 (头部声明+删字段) / 大数组采样
     (首 30% + 尾 15% + 错误项优先, 最多 15 项)
   - 非 JSON 日志: 重复行合并 (相同行 ×N) + 空行归一
2. 消息正文 (用户/助手历史 Text): 无损紧凑 (空行归一/重复行合并)

不压缩 (保证功能与缓存):
- system prompt (缓存前缀基础)
- 工具定义 tools 数组 (工具调用正常)
- 工具调用参数

## 铁律保障
- 缓存率凌驾一切: 纯规则确定性 (同输入同输出), 幂等 (二次压缩不变),
  压缩结果作为请求前缀与上一轮稳定一致
- 隔离: 开关关闭时 generateInternal 直接使用原 messages (zero-copy),
  压缩逻辑完全不执行

## 实现要点
- 压缩点: 从 generateText 开头移到每步发送点 generateInternal —
  覆盖 step 循环内累积的新工具输出 (所有会发送的内容)
- effectiveMessages: 开关开启时压缩, 关闭时原样; 工具 system prompt /
  API 消息组装 / 流式累积基准均用 effectiveMessages
- 编译修复: UIMessagePart.Text 字段为 text (非 content) — 上一版编译失败

## 压缩率实测 (JS 等价模拟)
- 50 项 JSON 数组: 55.9%
- 60 项含错误项: 52.2% (错误/首尾项保留)
- 30 项常量数组: 52.0%
- 重复日志: 89.5%
- 确定性/幂等: 通过
