# 2026-08-11 v3.6.21 — 百炼 SSE MCP "job was cancelled" 根因修复

## 现象
- 质朴 HTTP MCP 正常; 阿里云百炼同工具 (zhipu-websearch) SSE 格式
  报 "job was cancelled" (SDK 升级 0.15.0 后仍报)

## 根因 (源码级确认 — SDK main 分支)
- SseClientTransport: GET /sse 建立 SSE 流, collectMessages 收事件
- 工具调用: POST endpoint → 响应经 SSE 流回 → Protocol 匹配 deferred
- SSE 流断开 (百炼网关空闲/响应后关闭) → transport.onClose →
  Protocol.doClose → connection.handlerScope.cancel() →
  request 挂起 (deferred.await) 抛 JobCancellationException
  ("Job was cancelled") — 质朴 HTTP (StreamableHTTP) 无长连接, 无此路径

## 修复 (McpManager.callTool)
- catch JobCancellationException:
  - 用户停止 (协程不活跃) → 传播 (原行为)
  - 生成活跃 → 日志 + 重连 (addClient: 新 Client + connect + sync)
    + 重试一次 — 搜索类幂等工具可安全重试
  - 重连失败/重试再失败 → 抛原异常 (错误可见)

## 说明
- 仅针对 callTool 层 (所有 MCP 共用), 但只拦截 JobCancellationException
  且只在生成活跃时触发 — 其他 MCP/用户停止不受影响
- 百炼 SSE 流断开为平台行为, 重连重试是客户端侧唯一可靠恢复路径
