# v3.10.8 — 渲染内核引入 mikepenz (2026-08-24)

## 背景
自研 AST→Compose 渲染层节点映射不全: 表格/嵌套列表/任务列表/HTML/
引用等"该解析的没解析"。

## 变更
- 依赖 com.mikepenz:multiplatform-markdown-renderer-m3:0.44.0
- markdown 库统一官方 org.jetbrains:markdown 0.7.5 (原 rikkahub fork 退役)
- MarkdownKernel.kt: 新内核组件 (初版默认主题, 主题适配后续轮)
- MarkdownBlock 路由: 普通 markdown → 新内核; LaTeX/Mermaid/graphviz 特征 → 旧内核

## 影响面检验 (整体)
- 流式增量 (loading): 平滑期走旧内核 (异步解析安全), 完成后走 MarkdownBlock
  原生路由 (含新内核) — 避免 mikepenz 同步解析 30Hz 卡主线程
- 历史消息/版本切换/编辑: loading=false 直接全文, 零影响
- 传输/缓存/工具调用链路: 无接触
- 回退: MarkdownKernel.ENABLED 常量一键关
