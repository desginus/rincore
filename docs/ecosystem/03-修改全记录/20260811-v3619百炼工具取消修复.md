# 2026-08-11 v3.6.19 — 百炼 MCP 工具 "job was cancelled" 修复

## 现象
- 质朴 MCP 工具正常; 阿里云百炼平台上等效工具报 "job was cancelled"

## 根因
- "Job was cancelled" 是 JobCancellationException (CancellationException 子类)
- 来源: MCP Kotlin SDK 内部取消 (百炼 streamableHttp transport 偶发
  JobCancellationException) — 非用户停止, 非 60s 工具超时 (超时是
  TimeoutCancellationException, 消息不同, 已有专门处理)
- 原逻辑: 所有 CancellationException 一律 throw 向上传播 —
  SDK 内部取消被误判为"用户停止" → 生成中断报错

## 修复
- GenerationHandler 工具执行 onFailure: 区分用户取消 vs 工具内部取消
  - coroutineContext.isActive == false (用户停止) → 传播 (原行为)
  - isActive == true (生成仍活跃) → SDK/平台内部取消 → 转错误写回
    ("工具执行被平台中断，可重试") → 模型继续, 不误报中断
- 附带: CallTracer 记录 cancel_<tool> 事件 (可诊断)

## 说明
- 百炼偶发取消已不再中断生成; 模型看到错误可自行重试或换方式
- 副作用工具不自动重试 (防重复执行) — 由模型决策
