    文件系统偶发读取失败 → 该轮工具少 → 前缀断 (低概率)

    时 messages 含孤立 tool_call → 协议违规/前缀断 (低概率)
- 结论: 无确定性退化点; cache-fp 指纹日志 (SHA-256 system+tools) 可验证
  前缀稳定性 — 连续多轮一致即前缀稳定, 命中率取决于平台侧
