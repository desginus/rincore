# 文件系统桥接说明 (P2-7)

## 沙箱与宿主目录映射

| 沙箱路径 | 宿主机路径 | 说明 |
|---------|-----------|------|
| /skills | filesDir/SKILLS | 技能目录 (bind mount, 只读) |
| /upload | filesDir/UPLOAD | 用户上传区 (只读) |
| /tool_outputs | filesDir/TOOL_OUTPUTS | 工具输出 |
| /workspace | filesDir/workspaces/<id>/files | 工作区 (读写) |

## 不挂载的目录

- filesDir/ecosystem/ (插件/ClawHub 生态): 沙箱不可见, 插件内容经
  plugin__ 工具读取, 不需要沙箱直访。

## 排查要点

1. 沙箱内 ls 看不到某目录 ≠ 文件不存在 — 先查是否在挂载表内。
2. 挂载表单一来源: RepositoryModule 的 WorkspaceManager bindMounts,
   文件工具的路径解析同表 (禁止两处漂移)。
3. 新增目录需要沙箱可见时, 在挂载表加 WorkspaceBindMount 条目。
