# 批次经验总结 — v3.5.44 ~ v3.5.51 工具系统信源统一与中断根治

## 背景
用户连续多轮反馈: 工具数量三套口径 (411/399/376) 从未对上、幻影工具/幻影域、
Skill 四套口径、缓存半报废、输出中断。本批次系统重写工具系统数据链 + 根治中断。

## 核心架构 (最终形态)
1. 工具池: buildAssistantToolPool() — 唯一构建入口 (本地内置 + Skill + MCP +
   生态 + 框架 + workspace, 全部 Tool 对象同层位, 配置驱动无运行时状态)
2. 分类: classifyByName() — 唯一分类规则 (override 挂载键兼容 → skill 归根域 →
   系统前缀 → MCP 映射 → 关键词 → 未分类)
3. 视图: unifiedDomainView() — 唯一视图结构 (树 + 直接计数 + 子树计数 + 工具分组),
   所有消费者 (UI/系统 Prompt/Invoke Tools/List Domains/Search Domains/对照页/
   内置工具页) 只读这一个
4. 注入: 分层 (框架 + 已加载域) — 冷启动小; layer1 纯静态 (公共前缀恒定)

## 关键教训
1. 计数口径: 根域计数曾混入子域 (sumOf) → 显示 18 下钻 8。统一为直接工具数
   = 下钻可见数量; 子树另标含子域共 Y 个。计数必须等于用户能展开看到的数量。
2. 幻影工具: invoke_tools 叶子域的 allInParent 减法 (parentTools - subTools)
   在子域不在树时把子域工具混入根域 → 注册表有、下钻看不到。移除减法, 直接
   classified[域]。
3. 幻影域: ① 小写 system (metaToolNames) 与枚举「系统」并存 → 容错补树产生
   重复域; ② search_domains 手工枚举残留已删的 customDomains/技能子域 →
   搜索命中不存在域。统一: 分类键必须 ∈ 枚举路径; 搜索范围 = 统一视图真实域。
4. 工具池不一致: list_domains/search_domains 的 toolPoolProvider 曾缺
   workspaceRepository (5 个工具差) → 池参数必须与模型侧完全同参。
5. Skill 四套口径: Skills Lock (全量) / enabledSkills 过滤 / overrides 挂载 /
   invoke_tools skills 参数 — 全部统一: 技能工具全量生成 (skill__ 前缀) 进池,
   分类归根域, 挂载经 override 键兼容 (skill:名 ↔ skill__名 双向解析),
   移除独立 skills 参数 (自相矛盾提示消失)。
6. 缓存静态性: layer1 必须纯配置派生 (技能归根域后不随技能增删变化);
   tools 数组唯一动态 = 分层加载 (机制内); memory volatile 低频。
7. watchdog 教训 (v3.5.14 → v3.5.45 → v3.5.50): 主动断开曾误杀长思考;
   25s 无数据误杀实证 (Trace 95098f39: 平台静默期 >25s) → 120s 折中 +
   断流自动重试 (回滚半截输出 + 重试 2 次, 消息相同缓存命中)。
8. 断流重试: GenerationHandler collect 包 try-catch — IOException (网络/NAT/
   平台) → 回滚 preStreamMessages → 重试; CancellationException 不重试;
   HTTP 错误不重试。变量提升类成员规避作用域解析坑。
9. UI 导航: navigation3 的 entry lambda 无 navController — 新页面用设置页
   内嵌状态模式 (showXxxPage + return) 而非导航注册; HugeIcons 成员解析
   不可靠 (同名成员在不同文件 unresolved) — 新页面避免使用或去掉 leadingContent。

## 验证路径
- 计数: 域管理页各域直接之和 = 顶部总数 = 帮助工具池总数 = 内置工具页总数
- 下钻: 每域展开工具数 = 标注数 (含子域另标)
- 搜索: search_domains 返回的域 invoke_tools 可打开
- 技能: 技能域列出全部 skill__ 工具; 挂载技能在挂载域
- 缓存: 连续多轮 msg_fp 稳定; cache hit 率恢复
- 中断: 切后台/静默期不中断; 真断流自动重试恢复
