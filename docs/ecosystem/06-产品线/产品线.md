# 产品线说明

v3.8.45 起拆分为双产品线，同源代码库，Gradle productFlavors 构建。

## A 类主线 RinCore

- flavor: rincore
- 包名: me.rincore.app
- 版本: 3.9.0 起（继续沿用主版本链，前两位锁定，只升第三位）
- 定位: 个人定制完整客户端，历史所有功能 + HTML 渲染
- 签名: 旧密钥连续（已装用户可覆盖升级，数据保留）
- 数据: 与历史版本完全连续

## B 类产品线 WaterHub

- flavor: waterhub
- 包名: com.waterhub.app
- 版本: 0.0.1-beta 起步，独立版本体系
- 定位: 水利水电工程封堵工程试验数据处理与分析一体化 Agent 平台
- 数据: 与主线完全隔离（独立包名沙箱），可同时安装
- 注意: 正常推送不必读取 B 类版本，交付时特别标注即可

## 构建约定

- assembleRelease 同时产出两个 APK:
  - app/build/outputs/apk/rincore/release/
  - app/build/outputs/apk/waterhub/release/
- CI artifact:
  - rincore-release（A 类主线）
  - waterhub-release（B 类产品线，正常不读）
- 版本字段按变体输出（androidComponents.onVariants 覆写
  BuildConfig.VERSION_NAME/VERSION_CODE），不要回退到 buildTypes 硬编码
- app_name 等品牌字符串走 resValue 按 flavor 注入，
  不要在 main strings.xml 里硬编码产品名

## 修改注意

- 通用功能改 main 代码，双线同时生效
- 品牌/版本差异改 flavor 配置，禁止在代码里判断 flavor 分支
- 版本号变更必须同步 versionCode
