## 架构判断

3.2.0 的 `ChatService` 1518 行 + `ai/agent/AgentLoop` 255 行，比我们当前的 `ChatService 2609 + GenerationHandler 2555` 小得多；它已经是“harness 式”回合循环。**建议把 3.2.0 AgentLoop 作为新引擎移植到 `ai` 模块，放在 feature flag 后，逐步接管工具/记忆/工作区，而不是在 GenerationHandler 上继续加分支。**

DSH（DeepSeek Harness）是 MIT 的 TypeScript/Node harness；直接移植不现实，正确形态是“官方 dsh 作为 proot 内的 sidecar，通过本地 API 接入”。这属于下一阶段，不与 3.2.0 的 Kotlin AgentLoop 混做。
