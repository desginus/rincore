4. **3.1.1 未移植项**：`ModelsDevUpdater`（依赖 ModelRegistry 重构）、`SettingMediaProviderDetailPage`（依赖 ProviderSetting 重构）；二维码按用户定案不做。

## 架构判断

3.2.0 的 `ChatService` 1518 行 + `ai/agent/AgentLoop` 255 行，比我们当前 `ChatService 2609 + GenerationHandler 2555` 小得多；它已经是“harness 式”回合循环。**建议把 3.2.0 AgentLoop 作为新引擎移植到 `ai` 模块，放在 feature flag 后，逐步接管工具/记忆/工作区，而不是在 GenerationHandler 上继续加分支。** 本版未做该迁移。

DSH（DeepSeek Harness）是 MIT 的 TypeScript/Node harness；正确形态是“官方 dsh 作为 proot 内的 sidecar，通过本地 API 接入”，不与 Kotlin AgentLoop 混做。
