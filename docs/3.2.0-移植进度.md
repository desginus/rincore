## 待移植（按优先级）

1. **Phone Use（原生手机操作）**：见 `docs/PHONE-CONTROL-DESIGN.md`；建议 Mika 三路径 + DSH 三级点击 + 3.2.0 工具 schema，分 P1~P4。
2. **自动压缩（工具轮中途）**：3.2.0 用 `AgentLoop.pauseAfterTools`；我们当前是 `GenerationHandler`，本版只落了回合结束，工具轮中途需先有回合边界回调或迁移 AgentLoop。
3. **ChatListPreview 搜索固定/长对话性能**：我们当前的自定义预览搜索框本来就在 LazyColumn 外（固定），未照搬 3.2.0 的 Box 重构；长列表计算可后续用 `produceState + Dispatchers.Default`。
4. **默认提供商全开启 / STA1N 内置**：属于产品配置项，未改。
5. **Web UI 的 lastUsage 展示**：DTO 已有，前端 TS 未改。

## 架构判断

3.2.0 的 `ChatService` 1518 行 + `ai/agent/AgentLoop` 255 行，比我们当前 `ChatService 2609 + GenerationHandler 2555` 小得多；它已经是“harness 式”回合循环。**建议把 3.2.0 AgentLoop 作为新引擎移植到 `ai` 模块，放在 feature flag 后，逐步接管工具/记忆/工作区，而不是在 GenerationHandler 上继续加分支。** 本版未做该迁移。

DSH（DeepSeek Harness）是 MIT 的 TypeScript/Node harness；正确形态是“官方 dsh 作为 proot 内的 sidecar，通过本地 API 接入”，不与 Kotlin AgentLoop 混做。
