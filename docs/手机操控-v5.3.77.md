# 手机操控（Phone Use）v5.3.77 交付说明

## 已交付

- **无障碍服务**：`PhoneUseAccessibilityService`（主清单声明，用户在系统设置开启「RinCore 手机操控」后生效）。
- **屏幕读取**：读取可见窗口元素（文字、资源 ID、可点击/可输入/可滚动、选中/焦点、屏幕坐标），最多 150 条。
- **三级点击（DSH 风格）**：节点 `ACTION_CLICK` → 最近可点击祖先 → 坐标手势；长按同理优先 `ACTION_LONG_CLICK`，失败退化为 700ms 手势。
- **动作**：observe / screenshot / tap / long_press / swipe / scroll / type / press / open_app / list_apps / wait。
- **视觉路径**：截图（长边 ≤1568，JPEG）保存为聊天文件；模型按 0~1000 网格选坐标。
- **文字**：优先 `ACTION_SET_TEXT`；`submit` 时按 `ACTION_IME_ENTER`。
- **应用**：列出 launcher 应用、按包名/名称打开；支付/银行类硬拦截，禁止读屏与操作。
- **可视反馈**：`GestureIndicator` 用无障碍覆盖层显示点击/滑动落点，不需要悬浮窗权限。
- **入口**：助手设置 → 本地工具 →「手机操控」；开启时若服务未连接会跳到系统无障碍设置。

## 明确边界

- 本版是 **A11y + 视觉截图** 两条实际路径，未接入 ADB/Shizuku shell（需要额外配对/授权，不在本批硬塞）。
- 本应用自身在前台时不允许操作（避免模型点自己的审批/设置）；先 `open_app` 或 `press home`。
- 悬浮窗是推荐（可看/可停），不是硬前提；关闭时仍有手势落点提示。
- 无障碍服务被系统杀死后需重新连接；服务重连会自动登记到 `PhoneUseManager`。
