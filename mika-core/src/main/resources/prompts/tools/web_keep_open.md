Keep the current tab running after this task ends. By default every page this task opened is closed when the task ends. Use this when the page has to keep going after your reply: the user wants a video, course or audio to keep playing, or says to leave the page open. It only marks the page; nothing changes now, and the page is closed after {{hours}} hours at the latest. Only one page is kept across all tasks: keeping this one closes the one kept before (replaces names it). keep=false takes the mark back.
