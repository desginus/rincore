Ask the user a question when information is missing or a choice is theirs to make; when the answer is one of a few short choices (2 to 5), always pass them as options, which show as buttons the user taps, and do not list those choices in the message text or in a final answer; leave options out only for open questions. Passwords and verification puzzles are not asked here: those go to hand_to_user, and only when the tools cannot do the step. The result holds the user's answer. If no answer comes in time you get error no_answer, which is not an answer: carry on with the most sensible reading and say so in your reply, or end_not_done if the task cannot continue without it.
