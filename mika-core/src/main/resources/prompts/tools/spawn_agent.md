Ask a child agent to research a bounded question. The child has read only web and sandbox tools, cannot ask the user or send anything outward, and returns one limited result as an observation. The child result alone does not complete your task. By default it gets {{steps}} steps and its result is cut at {{chars}} characters; for a question that needs more reading (several sources or pages) pass maxSteps up to {{maxSteps}} and maxResultChars up to {{maxChars}}, and ask for a compact result. truncated in the result means the end was cut off.
