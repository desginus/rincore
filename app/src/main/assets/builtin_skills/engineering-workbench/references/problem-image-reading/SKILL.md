# 原则

**读图的目标不是"看懂大意"，而是"每个数值、单位、符号、下标都可核对"。**
这一步错了，后面全错，而且错得看起来很有道理。

你可以直接看图（当前路由已声明图片输入）。所以：
- 允许看图 → 但**关键数值仍要逐项复述**给学生确认，尤其是：
  数字（10 / 1.0 / 16）、单位（kN / N、mm / m、MPa / Pa）、下标（σ₁ vs σₓ，R_A vs R_B）、
  上下标与幂次（cm³、m⁴、10²）、正负号、方向箭头、支座类型。
- 看不清就**说看不清**，不许猜。给出位置描述（"图右下角第 3 行那个数值"），
  并给出你倾向的两种可能读法，请学生选。

# 步骤

1. **先看整图**：几张图？一页几题？→ 一页多题用 `mech_read_problem` 的 `split`（`{"mode":"auto"}` 可按空白自动切）。
2. **预处理**（`mech_read_problem` 的 `ops`）：
   - 默认 `auto_orient` + `autocontrast` 就够。
   - 手机斜拍 → `{"op":"deskew"}`；明显透视（纸面梯形）→ `{"op":"perspective"}`（或先 `auto_detect`）。
   - 浅色扫描 / 复印发灰 → `{"op":"enhance_text"}` 或 `{"op":"binarize"}`。
   - **小字读不清 → `{"op":"zoom","box":[l,t,r,b],"factor":3}`**（box 是 0–1 归一化）。
     这是最有用的一步：先把可疑区域放大成一张新图，再看。
   - `probe` 可以只读探测图片指标并给出建议 ops（对比度低 / 边框过小 / 有旋转）。
3. **转写结构**（默认提示词会要求这些字段）：
   `subject`、`statement_latex`、`given`（每条含量/符号/数值/单位）、`find`、
   `figure`（几何尺寸、标注、支座/连接/元件、坐标系、曲线关键点）、`tables`、`equations`、
   `constants`、`low_confidence`（低置信字段 + 位置 + 为什么不确定）、`unreadable`。
4. **核对**（有疑问时必做）：
   - `mech_verify_reading`：把你的转写渲染成图，与**原图并排**输出对照图 → 自己逐项比对。
   - `viz_annotate`：在原图上圈出/放大你读的那个数 → 再确认一次。
   - 现在你能看到对照图，**要真的去看**，而不是只看工具返回的 "ok"。
5. **复述给学生**：题目复述 + 存疑清单 → 等确认。图片题**未确认不得求解**。

# 硬性规则

- 只转写、不求解、不画解题图（标注讲解归 `viz_annotate`）。
- 看不清就说不清；宁可多问一句，不要脑补一个数。
- 单位、上下标、正负号是"字"，不是"意思"——照抄原图，不要顺手"规范化"。
- 表格与图表是题面的一部分：坐标轴名、单位、刻度、图例、关键点数值都要转写。
- 手写稿的 1/7、0/6、2/z、μ/u、下标数字尤其要放慢，必要时放大再读。

# 输出模板（复述时用）

```
【题目复述】
- 学科 / 题型：
- 题面：
- 已知（逐条：符号 = 数值 单位）：
- 所求：
- 图中要素：
- 公式：
【存疑】无 / 具体位置 + 两种读法
```
